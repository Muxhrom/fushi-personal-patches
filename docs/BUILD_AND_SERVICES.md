# 构建与原版在线服务

## 已验证的版本

2026-10-15 的改版基于 Fushi 2.9.1 / 安装包 2.9.1+16909，对应源码 `689f44456cd224641e916da4ef5bf38438771b29`，Flutter 3.44.0、Dart 3.12.0、Windows x64。

本次安装只替换了 `data/app.so`，保留原版宿主、Flutter 引擎、插件和原生组件。75 个安装根目录的 EXE/DLL 在替换前后逐文件哈希一致。安装原生组件不能从补丁仓库还原，应保留对应版本的官方安装包。

## 对应版本的构建路径

优先遵循上游 `docs/agent/build.md`、依赖锁和 `ci/apply-patches.sh`。本次使用 Flutter 的 `assemble` 目标 `release_bundle_windows-x64_assets` 生成 Windows release AOT，避免为小型 Dart 功能重新构建原生宿主。传入 `FUSHI_BUILD_VERSION=2.9.1`，构建工具中的 DartDefines 参数使用 Flutter 要求的编码形式。

这条路径的前提是对应 Flutter 引擎、Dart snapshot 格式、插件调用和资产都兼容。**以后每个版本都要重新核对**；升级了引擎、原生插件或资源时，可能需要完整构建。不要只根据版本号相近就替换 AOT。

本次遇到 `gen_snapshot` 栈溢出，按上游 Windows CI 的做法，仅调整了任务专用 SDK 中工具的栈大小后成功构建。这个构建环境调整没有修改安装版的引擎或系统安全设置。后续应先检查目标版本 CI 是否仍需同一调整。

## 在线服务是独立的验收要求

公开源码中的构建占位配置不足以提供官方包全部在线功能。上游 `.github/actions/provide-baked-secrets/action.yml` 注入的应用级配置包括：

- Google 桌面 OAuth client secret。
- 日志上传 endpoint 和 token。
- 弹弹play app ID 和 app secret。
- TMDB 默认 API key。
- OpenSubtitles 默认 API key。

这些配置的实际值不在本仓库中。用户账号令牌、数据库、浏览记录和 WebView 资料也不在本仓库中。

本次使用独立的本地分析环境，从官方安装包中定位对应消费函数，并将七项原值仅在本机用于构建；没有把实际值交给模型、输出日志或上传。最终候选二进制逐项验证了精确原值及其函数引用，一共七项一致，测试占位值全部消失。

这项证据只适用于本次记录的版本。未来版本中配置可能变化，不能直接复用旧值、旧对象偏移或旧版 AOT。后续维护者须先确定合法可用的本机构建配置及来源，核对与新官方包的功能一致性。配置尚未取得或保留情况尚未验证时，保留用户现有安装，不以空值或占位值进行替换。

`skip-worktree` 是 Git 本地索引标记。采用复制目录、重新初始化仓库或手工上传时，它不会保护实际文件内容。每次上传应使用明确的文件清单并检查待提交的内容与历史。

## 隔离运行与替换

本次使用上游已有的 `FUSHI_TEST_ROOT` 隔离数据库、偏好和目录，并指定独立的 `FUSHI_WEBVIEW2_USER_DATA_FOLDER`。隐藏测试使用 `FUSHI_TEST_HIDDEN`；检查实际界面时使用隔离资料的可见窗口。以后先确认这些测试入口在目标版本仍可用。

通过本地 WebSocket 发送人工日文测试句，验证实际应用收到文本后写入 Windows 剪贴板；测试前保留剪贴板内容，测试后恢复。日常安装目录本身也执行了隔离文本流测试。

替换前备份原版 `app.so` 并核对哈希，确认原程序退出，再把校验通过的候选文件在目标目录暂存并原子替换。恢复副本和恢复脚本保留本机。用户的个人资料和登录数据保持原位。

源码测试通过、配置字节一致、在线服务真实请求成功是不同证据。当前在线服务没有逐项重新登录测试，真实游戏抓取也未作为这次新功能的运行时测试源；应如实保留这些验证边界。
